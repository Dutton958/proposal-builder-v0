# 服務建議書編排工具 V0.0 測試版

依國防部副食供應中心評選須知（GS15003L「豬肉鬆等64項」）自動編排「服務建議書」，產出可編輯的 Word 檔。

- **線上使用**：開啟本儲存庫的 GitHub Pages 網址（Chrome 或 Edge）。
- **離線使用**：下載 `服務建議書編排工具_V0.0_離線版.html`，用 Chrome 或 Edge 直接開啟，不需網路。
- **使用說明**：`使用說明_V0.0測試版.pdf`

V0.0 為測試版：「03 章節與佐證」、廠商名稱與投標項次皆為空白。所有資料只存在使用者自己的瀏覽器中，不會上傳到任何伺服器。
